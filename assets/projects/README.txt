Add your real app screenshots in this folder and reference them from `data/site-content.json`.

Example:

"screenshots": [
  {
    "src": "assets/projects/exacto-home.jpg",
    "alt": "Exacto home and booking screen"
  },
  {
    "src": "assets/projects/exacto-consultation.jpg",
    "alt": "Exacto consultation scheduling screen"
  }
]

Recommended:
- Use 2-4 screenshots per project
- Prefer portrait mobile screenshots for app projects
- Keep file sizes compressed for faster loading
